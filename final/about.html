About Casual Game Finder

Casual Game Finder is a curated collection of games designed to help players quickly discover games that fit their play style, platform, and experience level.

Why This Site Exists

With so many games available today, finding the right one can be overwhelming. This project focuses on clarity, simplicity, and accessibility.

What You Can Do

  • Browse a large collection of games
  • Filter by platform, genre, difficulty, and rating
  • Save preferences and explore featured picks

Project Details

This website was built as part of a web development course using semantic HTML, responsive CSS, and JavaScript.

How Casual Game Finder Works

Game data is stored in a local JSON file and loaded dynamically using JavaScript. Filters allow users to narrow results based on their preferences.

Your theme preference and subscription information are stored using LocalStorage, providing a more personalized experience.
